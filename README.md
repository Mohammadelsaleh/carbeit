# Carbeit 🚗💨

Carbeit is a modern, responsive, full-stack car trading platform designed for seamless automotive discovery and vehicle listings. The application provides an intuitive dashboard experience tailored for both prospective car buyers and private automotive sellers.

## ✨ Features

- **Dynamic Vehicle Search & Discovery:** Multi-parameter inventory filtering allowing users to search by keyword/brand or filter by maximum budget restrictions.
- **Structural Classification Filters:** Quick-access categorization shortcuts enabling instant sorting across vehicle body styles including SUVs, Sedans, Coupes, Hatchbacks, Convertibles, and Wagons.
- **Interactive UI/UX:** A visually striking, high-contrast hero banner interface overlaid with sleek luxury supercar backdrops designed for optimized text readability.
- **Seller Studio & Admin Ecosystem:** Built-in modular capabilities supporting seller authentication, inventory uploads, and localized listing management.

## 🛠️ Tech Stack

- **Frontend Core:** React.js (built using Vite)
- **Styling Utility:** Tailwind CSS
- **State Management:** React hooks (`useState`, `useEffect`)
- **Version Control:** Git & GitHub
